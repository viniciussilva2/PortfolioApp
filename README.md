# 💼 Portfólio Dev — React + .NET com ANTIGRAVITY

Projeto de portfólio desenvolvido como estudo prático, adotando a abordagem de **vibe coding** — priorizando fluidez, experimentação e iteração rápida durante o desenvolvimento.

A aplicação exibe informações profissionais, experiências (mockadas) e projetos reais consumidos diretamente da API do GitHub.

---

## 🚀 Tecnologias utilizadas

### Frontend
- React
- JavaScript / TypeScript (se aplicável)
- CSS / Styled Components / Tailwind (ajustar conforme usou)

### Backend
- .NET (ASP.NET Core)

### Integrações
- API pública do GitHub

### Outros
- Dados mockados para experiências profissionais
- Consumo de API via HTTP (GET)

---

## 🧠 Conceitos aplicados

- Vibe Coding (desenvolvimento orientado à fluidez)
- Separação de responsabilidades (frontend / backend)
- Consumo de API REST
- Tratamento de dados assíncronos
- Estruturação de componentes reutilizáveis no React
